# Первый пост канала Omni Message (черновик)

> Опубликовать вместе с запуском закрытой беты / накануне неё.

---

Omni Message — твой контроль над Telegram. ⚡

Официальный клиент мессенджера прекрасен, но он играет по правилам, которые не всегда защищают твои интересы. Собеседники видят, когда ты читаешь сообщения, авторы каналов знают, что ты смотрел их Истории, а случайное удаление важного сообщения из чата стирает его навсегда.

Omni Message (на базе форка DrKLO/Telegram) возвращает контроль в твои руки.

🔒 **Честно о приватности:**

Мы не обещаем «абсолютную анонимность». Любой клиент Telegram привязан к номеру телефона, а метаданные проходят через серверы компании. Но Omni Message делает максимум из того, что возможно реализовать на стороне приложения:

1. **Раздельный Ghost Mode:** читай сообщения без отправки галочек, скрывай статус «печатает» или «записывает голосовое».
2. **Anti-Recall (Локальный бэкап):** если собеседник удалил или изменил сообщение — у тебя оно останется в первоначальном виде с пометкой «удалено».
3. **Обход ограничений контента:** сохраняй медиафайлы и копируйте текст даже из защищенных каналов и чатов с запретом на скачивание.
4. **Скрытие активности:** просматривай чужие Сторис и посты в каналах абсолютно незаметно.
5. **Встроенный умный прокси:** приложение работает «из коробки» даже в условиях жестких блокировок, автоматически подбирая самый быстрый рабочий прокси.
6. **Защита устройства:** очистка EXIF-метаданных с фотографий перед отправкой, запрет скриншотов и защита отдельных чатов кастомным код-паролем.

🛡 **Прозрачность и безопасность:**

Проект развивается на базе открытого исходного кода (GPL-2.0). В Omni Message полностью вырезана любая телеметрия и трекеры отслеживания (Firebase Analytics и прочие коммерческие SDK). Весь код будет опубликован на GitHub, чтобы каждый мог убедиться в безопасности сборки.

Скачивание клиента будет доступно напрямую через этот канал в формате APK-файла (для Android).

Продукт находится в стадии активной разработки фундамента. Подписывайся, чтобы не пропустить закрытый бета-тест первой сборки! 🚀

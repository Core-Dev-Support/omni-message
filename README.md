# Omni Message

Неофициальный клиент Telegram для Android: приватность, кастомизация и устойчивая связь в условиях блокировок.

**Статус:** активная разработка, ранняя стадия. Репозиторий публичный — этого требует
GPL-2.0 при распространении APK, плюс публичные репозитории дают безлимитные минуты
Actions и бесплатные раннеры с 8 ядрами.

## Что это

Форк [DrKLO/Telegram](https://github.com/DrKLO/Telegram) (GPL-2.0) с фокусом на:

- Ghost Mode (прочтения / онлайн / typing — раздельно), Anti-Recall, скрытие просмотров
- работу «из коробки» в сетях с блокировками (авто-подбор MTProto-прокси, прозрачный индикатор)
- полную кастомизацию интерфейса (темы .attheme, Material You, AMOLED)
- ноль телеметрии и рекламных SDK; открытые исходники и воспроизводимая сборка

Пакет: `com.naua_omni_message.app` · ABI: `armeabi-v7a`, `arm64-v8a`

## Сборка

Сборка идёт в GitHub Actions (`.github/workflows/build.yml`) — коммит в `main` запускает
сборку, готовый APK появляется в Artifacts. Подробности и разбор известных проблем:
[docs/BUILD.md](docs/BUILD.md).

## Лицензия

Исходный код распространяется под GPL-2.0 (унаследовано от DrKLO/Telegram).
Проект не аффилирован с Telegram FZ-LLC и не использует официальную торговую марку.
